# Personal Website

A responsive personal portfolio for presenting astrophysics, engineering, instrumentation, research, and technical projects.

## Structure

- `index.html` — page content and portfolio sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and reveal interactions
- `resume.pdf` — optional; add this file to enable the résumé link already included on the page

## Customize next

Search `index.html` for placeholder text. In particular:

1. Replace `YOUR_EMAIL_HERE` with your preferred public contact email.
2. Replace the LinkedIn `href="#"` with your profile URL.
3. Expand the Education and Experience sections with dates, roles, accomplishments, and relevant coursework.
4. Replace future-project cards with completed work.
5. Add project images/screenshots when available.
6. Add `resume.pdf` to the repository root.

## Publishing

This is a static site and can be hosted directly with GitHub Pages. In the repository settings, enable Pages and deploy from the `main` branch/root directory.
